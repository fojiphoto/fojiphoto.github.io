FAQ

Straight Answers

Build new, or port an existing game?

If you already have a mobile game, porting is almost always cheaper — the design and art already exist. See the free port assessment.

Why do WebGL builds perform so badly by default?

Browsers cap memory well below a phone, and a straight Unity export ignores that. Build size, texture compression, audio streaming and draw calls all have to be reworked — that's the actual job.

Do you handle the portal submissions?

Yes — each portal has its own SDK, build limits and review bar. We handle each; you approve once.

How does the money work on portals?

Most run an ad revenue share; some pay licensing for exclusivity. Terms vary and we'll walk you through which suit your game.

Do we own the game?

Yes — code, art and IP, contractually.
